# Pocket ChatGPT Bridge

집에 켜둔 Windows 노트북의 ChatGPT를 밖에서 iPhone으로 조작합니다. 폰의 공식 ChatGPT 계정은 바꾸지 않습니다. 폰에서 쓴 문장은 데스크톱의 기존 대화에 입력되고, 답변과 이전 내역은 폰 너비에 맞는 채팅 화면에서 글자로 읽습니다. 유료 모델 API를 호출하지 않습니다. 로컬 대화 목록과 메시지는 공식 app-server의 읽기 API로 조회합니다.

## 집에서 준비

Windows 10/11과 로그인된 ChatGPT 데스크톱 앱이 필요합니다. **EXE 버전은 Python을 따로 설치하지 않아도 됩니다.**

1. 노트북을 충전기에 연결하고 덮개를 연 채 로그인 상태로 둡니다. 사용할 기존 로컬 Work 대화를 열어 둡니다.
2. `PocketChatGPTBridge.exe`를 더블클릭합니다. ChatGPT 앱이 닫혀 있으면 열고, 서버 실행과 자동 절전 방지, Tailscale 설치·연결·HTTPS 설정을 순서대로 진행합니다.
3. 첫 실행에서 Windows 설치 승인이 뜨면 허용하고, 열린 브라우저에서 Tailscale 로그인과 연결 승인을 완료합니다. 이후에는 로그인 상태를 재사용합니다.
4. iPhone에도 Tailscale을 설치하고 **노트북과 같은 Tailscale 계정**으로 로그인해 연결합니다. 폰 설치·로그인은 폰에서 직접 진행합니다.
5. **아이폰의 기본 카메라로 실행 창의 QR 코드를 비추고, 카메라에 뜨는 링크를 누릅니다.** 인증까지 자동으로 처리되므로 연결 키를 입력하지 않습니다. 한 번 연결한 Safari는 연결을 기억합니다. 페이지를 즐겨찾기해 두면 다음부터 바로 열 수 있습니다. QR을 쓸 수 없을 때만 고급 정보의 자동 연결 링크를 사용합니다.

사용 중에는 실행 창을 켜둡니다. 창을 닫으면 서버와 자동 절전 방지 요청이 종료됩니다. Tailscale 자체는 다른 용도로도 쓸 수 있으므로 종료하거나 로그아웃하지 않습니다. 설치·로그인·HTTPS 설정이 끝난 다음 실행부터는 EXE를 여는 것으로 노트북 연결 준비를 진행합니다. Windows 잠금과 ChatGPT 로그인은 자동으로 해제하지 않습니다.

QR에는 인증 정보가 포함되므로 개인적으로 사용합니다. 인증 정보는 URL의 `#` 뒤에 담아 서버에 전송되지 않으며, 페이지를 열자마자 주소 표시줄에서 지웁니다. 인증 성공 후 Safari의 `localStorage`에 연결을 기억하고, **연결 해제**를 누르면 지웁니다. Safari 기록·웹사이트 데이터 삭제나 비공개 브라우징에서는 다시 QR을 스캔해야 할 수 있습니다.

소스로 실행할 때만 Python 3.10 이상 또는 uv가 필요합니다. 기존 `start.ps1`은 서버만 실행하는 개발용 경로이며 Tailscale 자동 설정은 EXE 실행 창에서 처리합니다.

서버는 `127.0.0.1`에서만 실행됩니다. Tailscale **Serve만 사용**하고 Funnel이나 공개 포트 포워딩은 사용하지 마세요. 폰의 ChatGPT 로그인과 Tailscale 로그인은 별개입니다.

## 폰에서 사용

- 대화 목록: 사이드바에 보이는 항목을 긁는 대신 **프로젝트를 포함한 로컬 대화를 최근 수정한 순서**로 조회합니다. 처음 100개를 표시하고 **이전 대화 더 보기**로 다음 목록을 받습니다. 검색은 불러온 제목을 필터링합니다. 일반 ChatGPT 웹 채팅이나 다른 실행 호스트의 대화까지 통합하는 기능은 아닙니다. 선택하면 공식 대화 링크로 앱에서 엽니다.
- 채팅: 선택한 대화의 내 메시지와 답변을 텍스트로 표시합니다. 마크다운, 코드 복사, 가로로 넘기는 표를 지원합니다. 저장된 내용을 2초마다 확인하며 직접 토큰 스트리밍하는 방식은 아닙니다. **이전 메시지 더 보기**로 12턴씩 과거 내용을 받습니다. 읽던 위치를 유지하고 새로고침해도 선택한 대화를 기억합니다. 업로드 이미지·생성 이미지·답변 속 이미지를 대화 안에 표시하며, 누르면 확대할 수 있습니다. 상단은 제목과 버튼이 있는 한 줄이며 대화 목록·연결 상태·설정·노트북 조작은 버튼을 눌렀을 때만 팝오버로 열립니다.
- 새 답변 알림: 안 보고 있던 대화에 새 답변이 완료되면 목록 오른쪽과 목록 버튼에 작은 파란 점이 표시됩니다. 그 대화의 최신 메시지를 확인하면 사라집니다. 위쪽 메시지를 읽거나 팝오버를 열어 둔 상태에서는 자동으로 읽음 처리하지 않습니다. 폰에 읽음 상태를 저장하고, 화면을 보고 있을 때 5초마다 확인하며 다시 열면 놓친 답변을 확인합니다. 처음 연결하기 전의 기존 내역은 초기 기준으로 삼습니다.
- 새 로컬 세션: 새 입력창을 열고 실행 위치 메뉴에서 **내 컴퓨터에서**를 선택합니다. 첫 메시지를 보내면 대화가 생성됩니다. 컨트롤을 찾지 못하면 중단합니다.
- 전송: 선택한 대화를 노트북에서 다시 열고 입력창이 나타나기를 기다린 뒤, UIA로 입력창을 찾고 붙여넣기·Enter로 보냅니다. 입력창이 모호하면 기본적으로 중단합니다. 기존 초안을 비우고 Enter로 보내는 설정을 사용하세요.
- 오른쪽 ⋯ → 노트북 조작: 어느 연결 모니터에 있든 ChatGPT를 찾습니다. 다른 창 뒤에 있어도 상태 확인과 목록 조회가 되며 최소화된 창도 인식합니다. 캡처·입력에 필요하면 자동으로 창을 복원하거나 앞으로 가져옵니다. 앱 자체와 잠금 해제된 Windows는 필요합니다. 대화 읽기와 별도로 승인 창 등을 조작할 때만 화면 캡처를 사용합니다. 모니터별 배율에 맞춰 입력·캡처 좌표를 처리합니다.
- 오른쪽 ⋯ → 화면 설정 → 전체 모니터 밝기: 내장 WMI / 외부 DDC 밝기 조절을 지원하는 화면은 밝기를 낮춥니다. 밝기 조절을 지원하지 않는 외부 화면이 있으면 Windows 영상 출력을 끄고 노트북 화면만 남깁니다. **원래대로**는 화면 출력과 저장된 밝기를 복원합니다. 연결됐다는 이유로 자동 변경하지 않습니다.
- 오른쪽 ⋯ → 화면 설정 → 외부 모니터 출력: **끄기 / 다시 켜기**로 밝기 변경과 별개로 제어할 수 있습니다. 모니터 전원 스위치를 끄는 기능이 아닙니다. 신호가 끊긴 뒤 절전하거나 ‘신호 없음’을 표시하는지는 모니터에 따라 다릅니다. 복구는 Windows에 저장된 이전 확장/복제 구성을 사용합니다.

이미지는 대화에서 확인된 참조만 인증된 경로로 제공합니다. 로컬 이미지는 메타데이터를 제거한 WebP로 최대 4096px까지 표시합니다. 애니메이션은 현재 한 프레임만 표시합니다. HTTPS 이미지는 연결 키를 보내지 않고 폰에서 직접 엽니다. 원본 파일 삭제·링크 만료·외부 서비스의 계정 권한 문제는 해결하지 않습니다.

## 밖에서 연결이 끊겼을 때

일시적인 통신 오류에는 토큰을 지우지 않고 재연결합니다. 응답이 끊긴 메시지는 같은 전송 번호를 유지합니다. 같은 문장을 다시 보내도 서버가 이미 접수했다면 다시 입력하지 않습니다.

**전송 결과 확인**은 메시지를 다시 입력하지 않고 서버 기록만 조회합니다. 결과가 불명확하면 화면으로 확인한 뒤 **대화 확인 후 새로 작성**을 선택하세요. 서버가 재시작되면 이전 결과를 알 수 없으므로 미확인 메시지를 자동으로 다시 입력하지 않습니다.

서버의 전송 기록은 메모리의 최대 2,000건입니다. 인증 정보는 폰 Safari의 `localStorage`에 기억하고, 미확인 문장은 현재 브라우저 세션의 `sessionStorage`에만 유지합니다. 별도 영구 채팅 기록은 만들지 않습니다.

## 절전과 화면

실행 중에는 자동 절전을 소프트웨어로 막고 종료하면 해제합니다. 디스플레이는 기존 시간 설정대로 꺼질 수 있습니다. 화면을 계속 켜두도록 요청하지 않지만, 원격 입력 중에도 꺼진 상태가 유지되도록 제어하지는 않습니다.

화면 꺼짐과 Windows 잠금은 다릅니다. **자동 잠금·덮개 닫기·수동 절전은 막지 않습니다.** 입력에는 잠금 해제된 데스크톱이 필요합니다. 일반 절전을 허용하려면 `start.ps1 -AllowSleep`을 사용하세요.

## 검사와 위치 보정

`python -m remote_bridge.app --list-windows`와 `--inspect`로 검사할 수 있습니다. 출력에는 사적인 채팅 제목이 포함될 수 있으니 공개하지 마세요.

UIA 탐색이 안 될 때만 실행할 PowerShell에 `REMOTE_ALLOW_COORDINATE_INPUT=1`과 보정한 `REMOTE_COMPOSER_X`, `REMOTE_COMPOSER_Y`를 설정해 좌표 대체 입력을 켭니다. `.env.example`은 설명용이며 자동으로 읽지 않습니다.

## 확인 범위

실제 Windows 테스트와 미검증 항목은 [TESTING.md](TESTING.md)에 기록합니다. 입력 성공 표시는 키 입력 전달을 뜻하며 응답 완료를 보장하지 않습니다. UIA와 새 대화 메뉴는 앱 버전에 영향을 받고 캡처는 다른 창에 가려질 수 있습니다. 대화의 로컬·클라우드 보관 방식은 기존 ChatGPT 앱이 결정합니다.

토큰은 `%LOCALAPPDATA%\ChatGPTRemoteController\pairing-token.txt`에 저장되며 공개 저장소에 넣지 않습니다. 비공식 도구이며 MIT 라이선스입니다.

실행기는 QR에 넣을 인증 정보를 자식 서버에 같은 값으로 전달하고, **인증된 준비 확인 요청이 성공한 뒤에만 QR을 표시**합니다. 상태 확인은 느린 화면 탐색과 분리하고 화면 조작은 전용 작업 스레드에서 순서대로 처리합니다. 앱 미발견·인증 실패·실제 통신 오류를 같은 ‘연결 끊김’으로 표시하지 않습니다.

## 자동 테스트

`pip install -e '.[test]'`, `pytest -q`, `node --test tests/test_mobile.cjs`를 실행합니다. Node 22 이상은 프런트엔드 테스트에만 필요합니다.

## EXE 빌드

GUI 사용이 가능한 Windows에서 `build-exe.ps1`을 실행합니다. `.venv` 개발 환경이 필요하며 `.[windows,desktop]`을 설치한 뒤 PyInstaller로 Python과 필요한 라이브러리, 웹 화면을 한 파일에 묶습니다. 결과는 `dist/PocketChatGPTBridge.exe`와 프로젝트 폴더에 생성됩니다. 빌드 도구와 개발 환경은 완성된 EXE를 사용하는 사람에게 필요하지 않습니다.
